Connect Your Google Health Account

  1. Follow developers.google.com/health/setup: in Google Cloud Console, create a project and enable Google Health API.
  2. In OAuth consent screen (External, Testing mode), add yourself as a Test user and add the googlehealth read-only scopes (activity_and_fitness, sleep, health_metrics_and_measurements, profile).
  3. In Credentials → Create OAuth client ID, choose Web application and add Authorized redirect URI: http://localhost:8765/callback.
  4. Paste your Google Client ID and Client Secret below and click Authorize with Google Health.
